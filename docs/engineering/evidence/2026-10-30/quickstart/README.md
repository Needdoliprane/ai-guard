# Quick start et commandes — 30 octobre 2026

Le [quick start](../../../../quickstart.md), relié au README racine, suit installation, prérequis, configuration privée, démarrage local, viewer, premier worker offline, refus, travail isolé, export neuf, arrêt/reprise et diagnostic. Les versions, limites et flags sont confrontés au binaire gelé SQLite327 et aux sources.

**PASS documentaire** : aides ciblées, syntaxe shell des blocs, liens et ancres ; revue indépendante Luna puis correction de cinq constats et relecture du delta. [Rapport auteur](implementation.md), [revue et résultats initiaux conservés](review.md), [empreintes](source.sha256).

Corrections : configuration extérieure recommandée de façon cohérente, recette Codex et export alignés sur l'effet réel vérifié, programme moteur personnalisé rappelé par invocation, chemins cités pour les espaces. Une configuration située dans le projet n'est pas interdite par le code : sa racine physique est exclue de l'import ; le guide recommande l'extérieur pour simplifier le parcours.

Les aides ne suffisent pas à qualifier un poste vierge : installation complète fresh-host **NOT_RUN** dans ce lot. Aucun rebuild, nouvelle stack, modèle ni matrice E2E n'a été relancé pour la documentation. Les parcours réels déjà exécutés sont référencés, avec leurs limites ; le TTY et l'authentification Claude ne sont pas présentés comme livrés.
